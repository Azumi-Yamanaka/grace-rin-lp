# 01. Grace Rin 共通管理台帳 設計書（社内限定）

ファイル名：`GR_共通管理台帳`（Google スプレッドシート 1ファイル・複数シート）
保存場所：Grace Rin の共有ドライブ `GR_社内管理/`（クライアントとは共有しない）
自動生成：`gas/Setup.gs` の `setupLedgers()` で下記シート・列・入力規則・書式を一括作成

> 1ファイルにまとめる理由：シート間参照（案件ID・パートナーID）を VLOOKUP/QUERY で完結でき、
> 権限管理も1か所で済むため。将来データ量が増えたら Looker Studio で集計・可視化する。

## 6. 案件別サマリー（数式のみ・手入力なし）

| 列 | 項目 | 数式の考え方 |
|---|---|---|
| A | 案件ID | `=FILTER(案件マスタ!A2:A, 案件マスタ!A2:A<>"")` |
| B | クライアント名 | 案件マスタから参照 |
| C〜I | 報酬区分別 売上 | `SUMIFS(収益!E:E, 収益!B:B, A2, 収益!D:D, 区分, 収益!F:F, "<>見込み")` |
| J | 売上合計（確定） | C〜I の合計 |
| K | 見込み額 | ステータス=見込み の合計 |
| L | 稼働工数合計 | `SUMIFS(収益!G:G, 収益!B:B, A2)` |
| M | 時間単価 | `=IFERROR(J2/L2,"")` → 収益性の指標 |

## 8. 選択肢マスタ

各プルダウンの選択肢を列ごとに保持。`setupLedgers()` はこのシートを参照して入力規則を張るため、
選択肢の追加はこのシートを編集 → メニュー「入力規則を再適用」で反映。
