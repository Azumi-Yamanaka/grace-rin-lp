# 01. 案件別フォルダ構成テンプレート

`案件マスタ` の「フォルダ作成」にチェックを入れると、GAS（`gas/CaseFolder.gs`）が下記を自動生成します。

## 命名規則

- 案件フォルダ：`{案件ID}_{クライアント名}`　例：`C001_株式会社サンプル`
- ファイル：`{案件ID}_{書類名}_{YYYYMMDD}`　例：`C001_ヒアリングシート_20261201`
- 版管理：Google ドキュメントの版履歴を使い、ファイル名に v1/v2 は付けない（確定版のみ PDF 化して `_確定` を付与）

## フォルダ階層

```
GR_案件フォルダ/（共有ドライブ）
└─ C001_株式会社サンプル/
   ├─ 01_ヒアリング/
   │   ├─ C001_ヒアリングシート_YYYYMMDD     ← TPLから自動コピー
   │   └─ 議事録/（Notta・Meet 文字起こし等）
   ├─ 02_環境調査/
   │   └─ C001_ツール活用診断_YYYYMMDD       ← TPLから自動コピー
   ├─ 03_業務分析/
   │   └─ 業務フロー図・業務棚卸し表
   ├─ 04_提案/
   │   └─ C001_業務改善提案書_YYYYMMDD       ← TPLから自動コピー
   ├─ 05_構築/
   │   ├─ 設計書/
   │   └─ テスト記録/
   ├─ 06_マニュアル・納品/
   │   └─ 運用マニュアル・引継書
   └─ 99_社内限定/                            ← クライアントと共有しない
       └─ 見積根拠・社内メモ
```

## 運用ルール

| ルール | 内容 |
|---|---|
| 共有範囲 | 案件フォルダ全体は共有しない。01〜06 のうち必要なものだけをクライアントに共有（**共有は事前承認**） |
| 社内限定情報 | 紹介報酬・収益・工数は `GR_共通管理台帳` のみ。案件フォルダ（99含む）にも書かない |
| 認証情報 | パスワード・APIキーはフォルダに置かない |
| 成果物の所有 | 構築物（GAS・AppSheet・Looker Studio 等）は **クライアントのアカウント内** に作る。このフォルダは設計・記録用 |
| 契約終了時 | 06 の引継書をクライアントに納品 → 共有解除 → フォルダは `_アーカイブ` へ移動（移動・削除は承認制） |
