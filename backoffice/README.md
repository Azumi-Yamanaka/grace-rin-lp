# Grace Rin バックオフィス基盤（設計・テンプレート一式）

Grace Rin の「案件別バックオフィス構築・業務自動化・ツール導入支援」を進めるための、
社内管理台帳の設計、クライアント向けテンプレート、Google Apps Script（GAS）の雛形です。

> **ステータス：設計段階（未デプロイ）**
> ここにあるのは設計書とコードの雛形だけです。Google アカウントへの接続、Drive へのファイル作成、
> トリガー設定、メール送信は一切行っていません。実施前に `docs/00_実装方針と承認事項.md` の承認が必要です。

## 構成

| パス | 内容 | 区分 |
|---|---|---|
| `docs/00_実装方針と承認事項.md` | 全体アーキテクチャ・導入手順・承認が必要な操作の一覧 | 社内 |
| `docs/01_共通管理台帳設計.md` | パートナー／紹介案件／案件別ツール管理台帳＋補助シートの列定義 | **社内限定** |
| `docs/02_GAS自動化設計.md` | 自動化対象・トリガー・ログ・権限・テスト/本番分離 | 社内 |
| `templates/01_案件別フォルダ構成.md` | クライアントごとのフォルダ階層と命名規則 | 社内 |
| `templates/02_ヒアリングシート.md` | 初回ヒアリング用（Googleドキュメント／フォーム化前提） | クライアント提示可 |
| `templates/03_ツール活用診断シート.md` | 契約環境・未活用機能の診断（スプレッドシート化前提） | クライアント提示可 |
| `templates/04_業務改善提案書.md` | 提案書テンプレート（紹介報酬額は記載しない） | クライアント提示可 |
| `gas/` | 台帳セットアップ・案件フォルダ自動作成・リマインド・ログ | 社内 |

## 情報の区分ルール

- **社内限定**：紹介報酬額、収益、工数、パートナー契約条件。Grace Rin の Google Workspace 内の社内台帳にのみ保存。クライアントと共有するフォルダには置かない。
- **クライアント提示可**：ヒアリングシート、診断シート、提案書。紹介報酬を受け取る可能性がある旨は「開示文」で明示するが、金額は記載しない。

## 注意（リポジトリ公開範囲）

このリポジトリは **public** で、`main` は GitHub Pages で LP として公開されています。
ここには実データ（顧客名・報酬額・紹介URL）を絶対にコミットしないでください。
設計書の保管先は、private リポジトリまたは Grace Rin の Google Drive への移設を推奨します。
